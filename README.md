# Embedded Systems Internship Tasks 🚀

This repository contains the hands-on tasks completed as part of my **Embedded Systems Internship**.  
Each task focuses on applying core embedded concepts using **Arduino**, sensors, and real-time control logic.

The projects demonstrate the integration of **hardware + software**, emphasizing practical learning, experimentation, and real-world problem solving.

---

## 🔧 Technologies & Tools Used

- Arduino UNO
- Embedded C / Arduino IDE
- Sensors (Temperature, Buttons, etc.)
- Serial Monitor
- Tinkercad Simulation
- Basic Electronics Components

## 📘 Task Details

### 🔹 Task 1: Temperature Sensor
- Interfaced a temperature sensor with Arduino
- Read real-time temperature values
- Displayed output using Serial Monitor
- Learned analog sensor interfacing and ADC concepts

---

### 🔹 Task 2: LED Control via Serial Communication
- Controlled LED ON/OFF using Serial Monitor commands
- Implemented conditional logic based on user input
- Understood serial communication and control flow

---

### 🔹 Task 3: Temperature Monitoring System
- Continuous temperature monitoring
- Triggered actions based on threshold values
- Introduced basic decision-making logic
- Improved real-time system understanding

---

### 🔹 Task 4: Speech-Based Control System
- Simulated speech-based LED control using buttons
- Implemented logic to represent voice commands
- Learned input simulation and control abstraction
- Built foundation for accessibility-based systems
